# PDF Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Локальная программа (`python app.py` → страница в браузере) для: картинки → PDF, объединение PDF, сжатие PDF, PDF → EPUB; файлами (drag & drop) или целой папкой.

**Architecture:** Чистые функции в пакете `pdftools/` (байты на вход → байты на выход, без веба), пакетная обработка папки в `pdftools/folder.py`, тонкий FastAPI-слой в `app.py`, одна статическая страница `static/index.html` на чистом JS.

**Tech Stack:** Python 3.14, PyMuPDF (`import pymupdf`), Pillow, ebooklib, FastAPI + uvicorn + python-multipart.

**Spec:** `docs/superpowers/specs/2026-10-12-pdf-tools-design.md`

## Global Constraints

- **Автотесты не пишем** (решение пользователя): никаких `tests/`, pytest и тестовых зависимостей. Каждая задача проверяется разовым smoke-скриптом, который запускается из scratchpad-папки и **не** коммитится.
- ОС: Windows 11; Python 3.14; команды запускаются из корня проекта через `.venv/Scripts/python`.
- Сервер слушает только `127.0.0.1`, порт `8765`.
- Все сообщения об ошибках для пользователя — на русском, через `PdfToolsError`; HTTP 400 `{"error": "..."}`; неожиданные — HTTP 500.
- **Битый файл отменяет всю обработку:** в режиме папки ничего не пишется в `готово/`, если хоть один файл дал ошибку; пользователь видит список всех проблемных файлов.
- Картинки: JPG, GIF (первый кадр), PNG, WEBP. HEIC — нет.
- Сжатие: `light` = 200 DPI / JPEG 85, `medium` = 150 / 70, `strong` = 100 / 50; если не стало меньше — вернуть оригинал.
- Папка: только файлы верхнего уровня, расширение без учёта регистра, естественная сортировка, результат в `<папка>/готово/`, исходники не меняются, существующие результаты перезаписываются.
- Выходные имена в режиме папки: картинки и объединение → `готово/<имя папки>.pdf`; сжатие → `готово/<то же имя>.pdf`; EPUB → `готово/<то же имя>.epub`.
- EPUB: reflowable EPUB 3; название по умолчанию — метаданные PDF, иначе имя файла без расширения.
- Функции принимают имена файлов вместе с байтами (`list[tuple[str, bytes]]` или параметр `name`), чтобы ошибки называли конкретный файл.
- Коммиты заканчиваются строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```python
import re

_DIGITS = re.compile(r"([0-9]+)")


def natural_key(name: str) -> tuple:
    """Ключ сортировки, при котором числа в имени сравниваются как числа: 2 < 10."""
    # split по группе всегда даёт [текст, число, текст, ...], поэтому
    # на одинаковых позициях сравниваются значения одного типа.
    parts = _DIGITS.split(name.casefold())
    return tuple(int(p) if i % 2 else p for i, p in enumerate(parts)), name
```

- [ ] **Step 1: Код** — `pdftools/images_to_pdf.py`:

```python
import io

import pymupdf
from PIL import Image, ImageOps, UnidentifiedImageError

from .errors import PdfToolsError

_EXIF_ORIENTATION = 0x0112


def images_to_pdf(items: list[tuple[str, bytes]]) -> bytes:
    """Склеивает картинки в один PDF: страница на картинку, размер страницы = размер картинки."""
    if not items:
        raise PdfToolsError("Нет картинок для конвертации")
    doc = pymupdf.open()
    for name, data in items:
        stream, width, height = _prepare(name, data)
        page = doc.new_page(width=width, height=height)
        page.insert_image(page.rect, stream=stream)
    return doc.tobytes(garbage=3, deflate=True)


def _prepare(name: str, data: bytes) -> tuple[bytes, int, int]:
    """Возвращает байты картинки, пригодные для PDF, и её размер с учётом поворота."""
    try:
        img = Image.open(io.BytesIO(data))
        img.load()  # у GIF загружается только первый кадр
    except (UnidentifiedImageError, OSError) as exc:
        raise PdfToolsError(f"«{name}»: не удалось открыть как картинку") from exc

    source_format = img.format
    orientation = img.getexif().get(_EXIF_ORIENTATION, 1)
    if source_format == "JPEG" and img.mode in ("RGB", "L") and orientation == 1:
        return data, img.width, img.height  # без перекодирования — без потерь

    img = ImageOps.exif_transpose(img)
    if img.mode in ("RGBA", "LA") or (img.mode == "P" and "transparency" in img.info):
        rgba = img.convert("RGBA")
        img = Image.new("RGB", rgba.size, "white")
        img.paste(rgba, mask=rgba.getchannel("A"))
    elif img.mode not in ("RGB", "L"):
        img = img.convert("RGB")

    buf = io.BytesIO()
    if source_format == "JPEG":
        img.save(buf, "JPEG", quality=95)
    else:
        img.save(buf, "PNG")
    return buf.getvalue(), img.width, img.height
```

```python
import pymupdf

from .errors import PdfToolsError
from .pdfio import open_pdf


def merge_pdfs(items: list[tuple[str, bytes]]) -> bytes:
    """Склеивает PDF в порядке списка, сохраняя закладки."""
    if not items:
        raise PdfToolsError("Нет PDF-файлов для объединения")
    out = pymupdf.open()
    toc = []
    for name, data in items:
        src = open_pdf(name, data)
        offset = out.page_count
        toc.extend([level, title, page + offset] for level, title, page in src.get_toc() if page > 0)
        out.insert_pdf(src)
        src.close()
    try:
        out.set_toc(toc)
    except ValueError:
        pass  # кривое оглавление в исходнике — объединяем без закладок
    return out.tobytes(garbage=3, deflate=True)
```

```python
from .errors import PdfToolsError
from .pdfio import open_pdf

# уровень → (максимальный DPI картинок, качество JPEG)
LEVELS = {"light": (200, 85), "medium": (150, 70), "strong": (100, 50)}


def compress_pdf(data: bytes, level: str = "medium", name: str = "PDF") -> bytes:
    """Пережимает картинки внутри PDF; текст и вектор не трогает."""
    if level not in LEVELS:
        raise PdfToolsError(f"Неизвестный уровень сжатия: {level}")
    dpi, quality = LEVELS[level]
    doc = open_pdf(name, data)
    # уменьшаем только картинки заметно плотнее целевого DPI
    doc.rewrite_images(dpi_threshold=int(dpi * 1.25), dpi_target=dpi, quality=quality)
    result = doc.tobytes(garbage=4, deflate=True, deflate_images=True, deflate_fonts=True)
    return result if len(result) < len(data) else data
```

- [ ] **Step 1: Код** — `pdftools/pdf_to_epub.py`:

```python
import hashlib
import html
import io
import math
import re
import uuid
from collections import Counter
from dataclasses import dataclass
from pathlib import Path

import pymupdf
from ebooklib import epub

from .errors import PdfToolsError
from .pdfio import open_pdf

MARGIN = 0.08            # доля высоты страницы сверху/снизу, где ищем колонтитулы
MIN_IMAGE_PX = 50        # картинки меньше — декор, пропускаем
HEADING_RATIO = 1.2      # во сколько раз шрифт крупнее основного, чтобы считаться заголовком
H1_RATIO = 1.6
MAX_HEADING_LEN = 150
SENTENCE_END = tuple('.!?:;…»"”)')
PAGE_NUMBER = re.compile(r"[-–—\s]*[0-9]{1,4}[-–—\s]*")
IMAGE_TYPES = {"jpeg": "image/jpeg", "jpg": "image/jpeg", "png": "image/png", "gif": "image/gif"}
CSS = """
body { font-family: serif; line-height: 1.5; }
p { text-indent: 1.5em; margin: 0 0 0.3em; }
h1, h2 { text-align: center; margin: 1em 0 0.6em; }
img { display: block; max-width: 100%; margin: 0.6em auto; }
"""


@dataclass
class Block:
    kind: str  # "text" | "image"
    text: str = ""
    size: float = 0.0
    image: bytes = b""
    ext: str = ""
    in_margin: bool = False


@dataclass
class Item:
    kind: str  # "p" | "h" | "img"
    text: str = ""
    level: int = 0
    image: bytes = b""
    ext: str = ""


def pdf_to_epub(data: bytes, title: str | None = None, author: str | None = None, name: str = "book.pdf") -> bytes:
    """Reflowable EPUB: абзацы, заголовки-главы, картинки; без колонтитулов."""
    doc = open_pdf(name, data)
    pages = _extract(doc)
    if not any(b.kind == "text" for blocks in pages for b in blocks):
        raise PdfToolsError(f"«{name}»: в PDF нет текста (скан). Распознавание текста пока не поддерживается")
    items = _to_items(_drop_running_heads(pages))
    meta = doc.metadata or {}
    book_title = title or (meta.get("title") or "").strip() or Path(name).stem
    book_author = author or (meta.get("author") or "").strip() or None
    return _build_epub(items, book_title, book_author)


def _join(left: str, right: str) -> str:
    if left.endswith("-") and right[:1].islower():
        return left[:-1] + right
    return f"{left} {right}"


def _block_text(raw: dict) -> tuple[str, float]:
    text = ""
    sizes: Counter[float] = Counter()
    for line in raw["lines"]:
        for span in line["spans"]:
            sizes[round(span["size"], 1)] += len(span["text"])
        line_text = "".join(span["text"] for span in line["spans"]).strip()
        if line_text:
            text = _join(text, line_text) if text else line_text
    return text, (sizes.most_common(1)[0][0] if sizes else 0.0)


def _extract(doc: pymupdf.Document) -> list[list[Block]]:
    pages = []
    for page in doc:
        height = page.rect.height
        blocks = []
        for raw in page.get_text("dict", sort=True)["blocks"]:
            y0, y1 = raw["bbox"][1], raw["bbox"][3]
            in_margin = y1 <= height * MARGIN or y0 >= height * (1 - MARGIN)
            if raw["type"] == 0:
                text, size = _block_text(raw)
                if text:
                    blocks.append(Block("text", text=text, size=size, in_margin=in_margin))
            elif raw.get("width", 0) >= MIN_IMAGE_PX and raw.get("height", 0) >= MIN_IMAGE_PX:
                blocks.append(Block("image", image=raw["image"], ext=raw["ext"]))
        pages.append(blocks)
    return pages


def _signature(text: str) -> str:
    return re.sub(r"[0-9]+", "#", text.casefold()).strip()


def _drop_running_heads(pages: list[list[Block]]) -> list[Block]:
    """Убирает колонтитулы (повторяются в полях на многих страницах) и номера страниц."""
    counts: Counter[str] = Counter()
    for blocks in pages:
        counts.update({_signature(b.text) for b in blocks if b.kind == "text" and b.in_margin})
    threshold = max(2, math.ceil(len(pages) / 2))
    kept = []
    for blocks in pages:
        for b in blocks:
            if b.kind == "text" and b.in_margin and (
                counts[_signature(b.text)] >= threshold or PAGE_NUMBER.fullmatch(b.text)
            ):
                continue
            kept.append(b)
    return kept


def _heading_level(block: Block, body_size: float) -> int:
    if len(block.text) > MAX_HEADING_LEN or block.size < body_size * HEADING_RATIO:
        return 0
    return 1 if block.size >= body_size * H1_RATIO else 2


def _to_items(blocks: list[Block]) -> list[Item]:
    sizes: Counter[float] = Counter()
    for b in blocks:
        if b.kind == "text":
            sizes[b.size] += len(b.text)
    body_size = sizes.most_common(1)[0][0]

    items: list[Item] = []
    seen_images = set()
    for b in blocks:
        if b.kind == "image":
            digest = hashlib.sha1(b.image).hexdigest()
            if digest not in seen_images:
                seen_images.add(digest)
                items.append(Item("img", image=b.image, ext=b.ext))
            continue
        level = _heading_level(b, body_size)
        if level:
            items.append(Item("h", text=b.text, level=level))
            continue
        prev = items[-1] if items else None
        # абзац, разорванный страницей или блоком: нет точки в конце, продолжение с маленькой буквы
        if prev and prev.kind == "p" and not prev.text.endswith(SENTENCE_END) and b.text[:1].islower():
            prev.text = _join(prev.text, b.text)
        else:
            items.append(Item("p", text=b.text))
    return items


def _language(text: str) -> str:
    letters = [c for c in text if c.isalpha()]
    cyrillic = sum(1 for c in letters if "а" <= c.lower() <= "я" or c in "ёЁ")
    return "ru" if letters and cyrillic / len(letters) > 0.3 else "en"


def _image_item(item: Item, n: int) -> epub.EpubItem | None:
    ext, data = item.ext.lower(), item.image
    if ext not in IMAGE_TYPES:  # jpx, jbig2 и т.п. читалки не понимают — переводим в PNG
        try:
            data, ext = pymupdf.Pixmap(data).tobytes("png"), "png"
        except Exception:
            return None
    return epub.EpubItem(
        uid=f"img{n}", file_name=f"images/img_{n:03}.{ext}", media_type=IMAGE_TYPES[ext], content=data
    )


def _build_epub(items: list[Item], title: str, author: str | None) -> bytes:
    lang = _language(" ".join(i.text for i in items[:300]))
    book = epub.EpubBook()
    book.set_identifier(str(uuid.uuid4()))
    book.set_title(title)
    book.set_language(lang)
    if author:
        book.add_author(author)
    css = epub.EpubItem(uid="style", file_name="style.css", media_type="text/css", content=CSS)
    book.add_item(css)

    split_level = 1 if any(i.kind == "h" and i.level == 1 for i in items) else 2
    sections: list[tuple[str, list[str]]] = [(title, [])]
    image_n = 0
    for item in items:
        if item.kind == "h":
            if item.level == split_level:
                if sections[-1][1]:
                    sections.append((item.text, []))
                else:
                    sections[-1] = (item.text, [])
            sections[-1][1].append(f"<h{item.level}>{html.escape(item.text)}</h{item.level}>")
        elif item.kind == "p":
            sections[-1][1].append(f"<p>{html.escape(item.text)}</p>")
        else:
            image_n += 1
            image = _image_item(item, image_n)
            if image:
                book.add_item(image)
                sections[-1][1].append(f'<img src="{image.file_name}" alt=""/>')

    chapters = []
    for n, (chapter_title, parts) in enumerate(sections, 1):
        if not parts:
            continue
        chapter = epub.EpubHtml(title=chapter_title, file_name=f"chapter_{n:03}.xhtml", lang=lang)
        chapter.content = "\n".join(parts)
        chapter.add_item(css)
        book.add_item(chapter)
        chapters.append(chapter)

    book.toc = chapters
    book.add_item(epub.EpubNcx())
    book.add_item(epub.EpubNav())
    book.spine = ["nav", *chapters]
    buf = io.BytesIO()
    epub.write_epub(buf, book)
    return buf.getvalue()
```

### Task 6: Пакетная обработка папки (всё или ничего)

**Files:**
- Create: `pdftools/folder.py`

**Interfaces:**
- Consumes: `natural_key`, `images_to_pdf`, `merge_pdfs`, `compress_pdf`, `LEVELS`, `pdf_to_epub`, `PdfToolsError`.
- Produces: `OUTPUT_DIR = "готово"`; `list_files(folder: Path, exts: set[str]) -> list[Path]`; `folder_images_to_pdf(folder: Path) -> list[Path]`; `folder_merge(folder: Path) -> list[Path]`; `folder_compress(folder: Path, level: str = "medium") -> list[Path]`; `folder_to_epub(folder: Path) -> list[Path]`. Каждая возвращает список созданных файлов; при любой ошибке бросает `PdfToolsError` и ничего не пишет.

- [ ] **Step 1: Код** — `pdftools/folder.py`:

```python
from collections.abc import Callable
from pathlib import Path

from .compress import LEVELS, compress_pdf
from .errors import PdfToolsError
from .images_to_pdf import images_to_pdf
from .merge import merge_pdfs
from .naming import natural_key
from .pdf_to_epub import pdf_to_epub

OUTPUT_DIR = "готово"
IMAGE_EXTS = {".jpg", ".jpeg", ".gif", ".png", ".webp"}
PDF_EXTS = {".pdf"}


def list_files(folder: Path, exts: set[str]) -> list[Path]:
    """Файлы верхнего уровня с нужными расширениями, в естественном порядке."""
    if not folder.is_dir():
        raise PdfToolsError(f"Папка не найдена: {folder}")
    files = [p for p in folder.iterdir() if p.is_file() and p.suffix.lower() in exts]
    if not files:
        raise PdfToolsError(f"В папке нет подходящих файлов ({', '.join(sorted(exts))})")
    return sorted(files, key=lambda p: natural_key(p.name))


def folder_images_to_pdf(folder: Path) -> list[Path]:
    folder = Path(folder).resolve()
    return _write(folder, {_combined_name(folder): images_to_pdf(_read(list_files(folder, IMAGE_EXTS)))})


def folder_merge(folder: Path) -> list[Path]:
    folder = Path(folder).resolve()
    return _write(folder, {_combined_name(folder): merge_pdfs(_read(list_files(folder, PDF_EXTS)))})


def folder_compress(folder: Path, level: str = "medium") -> list[Path]:
    if level not in LEVELS:
        raise PdfToolsError(f"Неизвестный уровень сжатия: {level}")
    return _each_pdf(Path(folder).resolve(), ".pdf", lambda src, data: compress_pdf(data, level, src.name))


def folder_to_epub(folder: Path) -> list[Path]:
    return _each_pdf(Path(folder).resolve(), ".epub", lambda src, data: pdf_to_epub(data, name=src.name))


def _read(paths: list[Path]) -> list[tuple[str, bytes]]:
    return [(p.name, p.read_bytes()) for p in paths]


def _combined_name(folder: Path) -> str:
    return f"{folder.name or 'результат'}.pdf"


def _write(folder: Path, outputs: dict[str, bytes]) -> list[Path]:
    out = folder / OUTPUT_DIR
    out.mkdir(exist_ok=True)
    created = []
    for name, data in outputs.items():
        target = out / name
        target.write_bytes(data)
        created.append(target)
    return created


def _each_pdf(folder: Path, suffix: str, convert: Callable[[Path, bytes], bytes]) -> list[Path]:
    """Сначала обрабатывает все PDF в памяти; если хоть один упал — ничего не пишет."""
    outputs: dict[str, bytes] = {}
    errors: list[str] = []
    for src in list_files(folder, PDF_EXTS):
        try:
            outputs[f"{src.stem}{suffix}"] = convert(src, src.read_bytes())
        except PdfToolsError as exc:
            errors.append(str(exc))
    if errors:
        raise PdfToolsError("Обработка отменена, ничего не сохранено. Проблемные файлы:\n" + "\n".join(errors))
    return _write(folder, outputs)
```

Примечание: для картинок и объединения «всё или ничего» получается само — `images_to_pdf`/`merge_pdfs` бросают ошибку на первом битом файле до записи.

### Task 7: HTTP API (FastAPI)

**Files:**
- Create: `app.py`

**Interfaces:**
- Consumes: всё из `pdftools`.
- Produces (для страницы из Task 8):
  - `POST /api/images-to-pdf` multipart `files` (несколько) → `application/pdf`, имя `картинки.pdf`
  - `POST /api/merge` multipart `files` → `application/pdf`, имя `объединённый.pdf`
  - `POST /api/compress` multipart `file`, form `level` → `application/pdf`, заголовки `X-Original-Size`, `X-New-Size`
  - `POST /api/epub` multipart `file`, form `title`, `author` (пустые = из PDF) → `application/epub+zip`
  - `POST /api/folder/{images|merge|compress|epub}` JSON `{"path": str, "level": str}` → `{"created": [str]}`
  - `POST /api/pick-folder` → `{"path": str}` (пустая строка, если отменили)
  - Ошибки: 400/500 `{"error": str}`; 404 для неизвестного действия; имя файла в `Content-Disposition: attachment; filename*=UTF-8''<urlencoded>`.

- [ ] **Step 1: Код** — `app.py`:

```python
"""Локальный веб-интерфейс PDF Tools. Запуск: python app.py"""
import logging
import threading
import webbrowser
from pathlib import Path
from typing import Annotated
from urllib.parse import quote

import uvicorn
from fastapi import FastAPI, File, Form, HTTPException, Request, UploadFile
from fastapi.concurrency import run_in_threadpool
from fastapi.responses import FileResponse, JSONResponse, Response
from pydantic import BaseModel

from pdftools import folder
from pdftools.compress import compress_pdf
from pdftools.errors import PdfToolsError
from pdftools.images_to_pdf import images_to_pdf
from pdftools.merge import merge_pdfs
from pdftools.pdf_to_epub import pdf_to_epub

HOST, PORT = "127.0.0.1", 8765
STATIC = Path(__file__).parent / "static"
log = logging.getLogger("pdftools")
app = FastAPI(title="PDF Tools")


@app.exception_handler(PdfToolsError)
async def _user_error(request: Request, exc: PdfToolsError) -> JSONResponse:
    return JSONResponse(status_code=400, content={"error": str(exc)})


@app.exception_handler(Exception)
async def _unexpected_error(request: Request, exc: Exception) -> JSONResponse:
    log.exception("Unexpected error")
    return JSONResponse(status_code=500, content={"error": "Внутренняя ошибка, подробности в консоли."})


def _file_response(data: bytes, filename: str, media_type: str, extra: dict[str, str] | None = None) -> Response:
    headers = {"Content-Disposition": f"attachment; filename*=UTF-8''{quote(filename)}", **(extra or {})}
    return Response(data, media_type=media_type, headers=headers)


async def _read_all(files: list[UploadFile]) -> list[tuple[str, bytes]]:
    return [(f.filename or "file", await f.read()) for f in files]


def _stem(filename: str | None) -> str:
    return Path(filename or "").stem or "result"


@app.get("/")
async def index() -> FileResponse:
    return FileResponse(STATIC / "index.html")


@app.post("/api/images-to-pdf")
async def api_images_to_pdf(files: Annotated[list[UploadFile], File()]) -> Response:
    data = await run_in_threadpool(images_to_pdf, await _read_all(files))
    return _file_response(data, "картинки.pdf", "application/pdf")


@app.post("/api/merge")
async def api_merge(files: Annotated[list[UploadFile], File()]) -> Response:
    data = await run_in_threadpool(merge_pdfs, await _read_all(files))
    return _file_response(data, "объединённый.pdf", "application/pdf")


@app.post("/api/compress")
async def api_compress(file: Annotated[UploadFile, File()], level: Annotated[str, Form()] = "medium") -> Response:
    original = await file.read()
    data = await run_in_threadpool(compress_pdf, original, level, file.filename or "PDF")
    sizes = {"X-Original-Size": str(len(original)), "X-New-Size": str(len(data))}
    return _file_response(data, f"{_stem(file.filename)}.pdf", "application/pdf", sizes)


@app.post("/api/epub")
async def api_epub(
    file: Annotated[UploadFile, File()],
    title: Annotated[str, Form()] = "",
    author: Annotated[str, Form()] = "",
) -> Response:
    original = await file.read()
    data = await run_in_threadpool(
        pdf_to_epub, original, title.strip() or None, author.strip() or None, file.filename or "book.pdf"
    )
    return _file_response(data, f"{_stem(file.filename)}.epub", "application/epub+zip")


class FolderRequest(BaseModel):
    path: str
    level: str = "medium"

    def folder(self) -> Path:
        # «Копировать как путь» в Проводнике добавляет кавычки
        return Path(self.path.strip().strip('"'))


FOLDER_ACTIONS = {
    "images": lambda req: folder.folder_images_to_pdf(req.folder()),
    "merge": lambda req: folder.folder_merge(req.folder()),
    "compress": lambda req: folder.folder_compress(req.folder(), req.level),
    "epub": lambda req: folder.folder_to_epub(req.folder()),
}


@app.post("/api/folder/{action}")
async def api_folder(action: str, req: FolderRequest) -> dict:
    if action not in FOLDER_ACTIONS:
        raise HTTPException(status_code=404, detail="Неизвестное действие")
    created = await run_in_threadpool(FOLDER_ACTIONS[action], req)
    return {"created": [str(p) for p in created]}


def _ask_directory() -> str:
    import tkinter as tk
    from tkinter import filedialog

    root = tk.Tk()
    root.withdraw()
    root.attributes("-topmost", True)
    try:
        return filedialog.askdirectory(title="Выбери папку") or ""
    finally:
        root.destroy()


@app.post("/api/pick-folder")
async def api_pick_folder() -> dict:
    path = await run_in_threadpool(_ask_directory)
    return {"path": str(Path(path)) if path else ""}


def main() -> None:
    logging.basicConfig(level=logging.INFO)
    url = f"http://{HOST}:{PORT}"
    threading.Timer(1.0, webbrowser.open, [url]).start()
    print(f"PDF Tools: {url}  (Ctrl+C — выход)")
    uvicorn.run(app, host=HOST, port=PORT)


if __name__ == "__main__":
    main()
```

```html
<script>
const TOOLS = {
  images: { label: "Картинки → PDF", accept: "image/jpeg,image/gif,image/png,image/webp", multiple: true,
            upload: "/api/images-to-pdf",
            hint: "Все картинки склеиваются в один PDF по порядку номеров. Папка → готово/<имя папки>.pdf" },
  merge:  { label: "Объединить PDF", accept: "application/pdf", multiple: true, upload: "/api/merge",
            hint: "PDF склеиваются по порядку номеров. Папка → готово/<имя папки>.pdf" },
  compress: { label: "Сжать PDF", accept: "application/pdf", multiple: false, upload: "/api/compress", options: "level",
            hint: "Пережимаются картинки внутри PDF, текст остаётся текстом. Папка → каждый файл в готово/ с тем же именем" },
  epub:   { label: "PDF → EPUB", accept: "application/pdf", multiple: false, upload: "/api/epub", options: "meta",
            hint: "Текст для читалки на телефоне. Название/автор — только для одного файла; папка → готово/<имя>.epub" },
};
const state = {};
const $ = (sel, el = document) => el.querySelector(sel);
const byNumber = (a, b) => a.name.localeCompare(b.name, undefined, { numeric: true, sensitivity: "base" });

function fmtSize(n) {
  return n < 1024 * 1024 ? `${Math.round(n / 1024)} КБ` : `${(n / 1024 / 1024).toFixed(1)} МБ`;
}
function setStatus(sec, text, kind = "") {
  const s = $(".status", sec);
  s.textContent = text;
  s.className = `status ${kind}`;
}
function filenameFrom(resp, fallback) {
  const m = (resp.headers.get("Content-Disposition") || "").match(/filename\*=UTF-8''([^;]+)/i);
  return m ? decodeURIComponent(m[1]) : fallback;
}
function download(blob, name) {
  const a = document.createElement("a");
  a.href = URL.createObjectURL(blob);
  a.download = name;
  a.click();
  setTimeout(() => URL.revokeObjectURL(a.href), 1000);
}
async function errorText(resp) {
  try { const d = await resp.json(); return d.error || d.detail || `Ошибка ${resp.status}`; }
  catch { return `Ошибка ${resp.status}`; }
}
async function busy(sec, fn) {
  const buttons = sec.querySelectorAll("button");
  buttons.forEach(b => b.disabled = true);
  setStatus(sec, "Работаю…");
  try { await fn(); }
  catch (e) { setStatus(sec, `Не удалось связаться с программой: ${e.message}`, "err"); }
  finally { buttons.forEach(b => b.disabled = false); }
}

function render(key, sec) {
  const list = $("ul.files", sec);
  list.innerHTML = "";
  state[key].forEach((file, i) => {
    const li = document.createElement("li");
    li.draggable = true;
    const label = document.createElement("span");
    label.textContent = `${i + 1}. ${file.name} — ${fmtSize(file.size)}`;
    const remove = document.createElement("button");
    remove.className = "secondary";
    remove.textContent = "✕";
    remove.title = "Убрать";
    remove.onclick = () => { state[key].splice(i, 1); render(key, sec); };
    li.append(label, remove);
    li.addEventListener("dragstart", e => { e.dataTransfer.setData("text/plain", String(i)); li.classList.add("dragging"); });
    li.addEventListener("dragend", () => li.classList.remove("dragging"));
    li.addEventListener("dragover", e => e.preventDefault());
    li.addEventListener("drop", e => {
      e.preventDefault();
      const from = Number(e.dataTransfer.getData("text/plain"));
      if (Number.isNaN(from)) return;
      const [moved] = state[key].splice(from, 1);
      state[key].splice(i, 0, moved);
      render(key, sec);
    });
    list.append(li);
  });
}

async function runUpload(key, sec) {
  const tool = TOOLS[key], files = state[key];
  if (!files.length) return setStatus(sec, "Сначала добавь файлы", "err");
  const form = new FormData();
  for (const f of files) form.append(tool.multiple ? "files" : "file", f);
  if (tool.options === "level") form.append("level", $(".level", sec).value);
  if (tool.options === "meta") { form.append("title", $(".title", sec).value); form.append("author", $(".author", sec).value); }
  await busy(sec, async () => {
    const resp = await fetch(tool.upload, { method: "POST", body: form });
    if (!resp.ok) return setStatus(sec, await errorText(resp), "err");
    const name = filenameFrom(resp, "result");
    download(await resp.blob(), name);
    let msg = `Готово: ${name}`;
    const before = resp.headers.get("X-Original-Size"), after = resp.headers.get("X-New-Size");
    if (before) msg += `\nРазмер: ${fmtSize(+before)} → ${fmtSize(+after)}`;
    setStatus(sec, msg, "ok");
  });
}

function setPath(value) {
  document.querySelectorAll(".path").forEach(input => input.value = value);
}

async function pickFolder(sec) {
  await busy(sec, async () => {
    const resp = await fetch("/api/pick-folder", { method: "POST" });
    const data = await resp.json();
    if (data.path) setPath(data.path);
    setStatus(sec, "");
  });
}

async function runFolder(key, sec) {
  const path = $(".path", sec).value.trim();
  if (!path) return setStatus(sec, "Укажи папку", "err");
  await busy(sec, async () => {
    const resp = await fetch(`/api/folder/${key}`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ path, level: $(".level", sec).value }),
    });
    if (!resp.ok) return setStatus(sec, await errorText(resp), "err");
    const data = await resp.json();
    setStatus(sec, "Создано:\n" + data.created.join("\n"), "ok");
  });
}

function wire(key, sec) {
  const tool = TOOLS[key], drop = $(".drop", sec), input = $("input[type=file]", sec);
  const add = fileList => {
    const picked = [...fileList];
    state[key] = tool.multiple ? [...state[key], ...picked] : picked.slice(0, 1);
    state[key].sort(byNumber);
    render(key, sec);
  };
  drop.addEventListener("click", () => input.click());
  input.addEventListener("change", () => { add(input.files); input.value = ""; });
  drop.addEventListener("dragover", e => { e.preventDefault(); drop.classList.add("over"); });
  drop.addEventListener("dragleave", () => drop.classList.remove("over"));
  drop.addEventListener("drop", e => { e.preventDefault(); drop.classList.remove("over"); add(e.dataTransfer.files); });
  $(".run-upload", sec).addEventListener("click", () => runUpload(key, sec));
  $(".pick", sec).addEventListener("click", () => pickFolder(sec));
  $(".run-folder", sec).addEventListener("click", () => runFolder(key, sec));
  $(".path", sec).addEventListener("input", e => setPath(e.target.value));
}

function show(key) {
  document.querySelectorAll(".tabs button").forEach(b => b.classList.toggle("active", b.dataset.tab === key));
  document.querySelectorAll("#panels section").forEach(s => s.hidden = s.dataset.tool !== key);
}

function build() {
  const tabs = $(".tabs"), panels = $("#panels"), tpl = $("#panel-tpl");
  for (const [key, tool] of Object.entries(TOOLS)) {
    state[key] = [];
    const btn = document.createElement("button");
    btn.textContent = tool.label;
    btn.dataset.tab = key;
    tabs.append(btn);
    const sec = tpl.content.firstElementChild.cloneNode(true);
    sec.dataset.tool = key;
    $(".hint", sec).textContent = tool.hint;
    const input = $("input[type=file]", sec);
    input.accept = tool.accept;
    input.multiple = tool.multiple;
    if (tool.options) $(`.opt-${tool.options}`, sec).hidden = false;
    panels.append(sec);
    wire(key, sec);
  }
  tabs.addEventListener("click", e => { if (e.target.dataset.tab) show(e.target.dataset.tab); });
  show("images");
}
build();
</script>
</body>
</html>
```

- [ ] **Step 2: README** — `README.md`:

```markdown
# PDF Tools

Локальная программа: картинки → PDF, объединение PDF, сжатие PDF, PDF → EPUB.
Файлы никуда не отправляются — всё работает на этом компьютере.

## Установка (один раз)

    python -m venv .venv
    .venv\Scripts\python -m pip install -r requirements.txt

## Запуск

    .venv\Scripts\python app.py

Откроется страница http://127.0.0.1:8765. Закрыть программу — Ctrl+C в окне консоли.

## Папки

Укажи папку — обработаются все подходящие файлы в ней (без подпапок) по порядку номеров
в именах (1, 2, …, 10). Результат появится в подпапке `готово`.
Если хотя бы один файл битый, обработка отменяется целиком и ничего не сохраняется —
программа покажет список проблемных файлов.
```
