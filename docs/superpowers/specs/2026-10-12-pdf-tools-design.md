# PDF Tools — дизайн

Дата: 2026-10-12

## Цель

Локальная программа для личного использования с четырьмя функциями:

1. Конвертация картинок в PDF.
2. Объединение нескольких PDF в один.
3. Сжатие PDF.
4. Конвертация PDF в EPUB для чтения в читалке на телефоне.

Все файлы обрабатываются локально и никуда не отправляются.

**Успех:** пользователь запускает `python app.py`, в браузере открывается страница,
он перетаскивает файлы, нажимает кнопку и скачивает результат.

## Архитектура

```
pdf_tools/
  app.py                  # FastAPI-сервер, при запуске открывает браузер
  pdftools/
    __init__.py
    errors.py             # PdfToolsError — понятные ошибки для пользователя
    images_to_pdf.py
    merge.py
    compress.py
    pdf_to_epub.py
  static/index.html       # одна страница, 4 вкладки, drag & drop
  tests/
  requirements.txt
```

Модули в `pdftools/` не зависят от веба: принимают байты и параметры, возвращают байты.
`app.py` — тонкий слой: принимает загрузку, вызывает функцию, отдаёт файл.

Сервер слушает только `127.0.0.1`.

## Функции

### Картинки → PDF — `images_to_pdf(images: list[bytes]) -> bytes`

- Основные форматы: JPG и GIF; также поддерживаются PNG и WEBP (их Pillow открывает без доп. зависимостей). HEIC не поддерживается.
- Одна картинка = одна страница, размер страницы равен размеру картинки.
- Порядок страниц = порядок в списке (на странице его можно менять перетаскиванием).
- Поворот применяется по EXIF.
- GIF: берётся первый кадр (анимированных не ожидается). Прозрачность заменяется белым фоном. Палитровые и RGBA-картинки переводятся в RGB.
- JPG без прозрачности вставляется без перекодирования, чтобы не терять качество.

### Объединение — `merge_pdfs(pdfs: list[bytes]) -> bytes`

- Склеивает PDF в заданном порядке, закладки (оглавление) сохраняются.

### Сжатие — `compress_pdf(pdf: bytes, level: Literal["light","medium","strong"]) -> bytes`

| Уровень | Макс. DPI картинок | Качество JPEG |
|---|---|---|
| light  | 200 | 85 |
| medium | 150 | 70 |
| strong | 100 | 50 |

- Пережимаются только картинки внутри PDF, текст и векторная графика не трогаются.
- Дополнительно: сборка мусора, сжатие потоков, удаление дублей объектов.
- Если результат не меньше оригинала, возвращается оригинал.
- В интерфейсе показывается размер «было → стало».

### PDF → EPUB — `pdf_to_epub(pdf: bytes, title: str | None, author: str | None) -> bytes`

- Результат — reflowable EPUB 3: текст переносится под ширину экрана телефона.
- Текстовые блоки PyMuPDF склеиваются в абзацы; переносы слов на концах строк убираются.
- Заголовки: блоки, у которых шрифт заметно больше основного (основной = самый частый размер),
  становятся `<h1>`/`<h2>`, и по ним делятся главы и строится оглавление.
- Колонтитулы и номера страниц убираются: короткие строки, которые повторяются в верхней или нижней
  полосе на многих страницах, а также строки из одних цифр.
- Картинки переносятся в EPUB в порядке появления.
- Название и автор по умолчанию берутся из метаданных PDF, в интерфейсе их можно изменить.
- Если в PDF нет текстового слоя (скан), выдаётся ошибка «В PDF нет текста (скан). Распознавание текста пока не поддерживается».

## Обработка ошибок

- Все ожидаемые ошибки — `PdfToolsError` с сообщением на русском:
  повреждённый файл, PDF с паролем, неподдерживаемый формат картинки, пустой список файлов, скан без текста.
- `app.py` превращает `PdfToolsError` в HTTP 400 с текстом; страница показывает его пользователю.
- Неожиданные ошибки — HTTP 500 с общим сообщением; подробности пишутся в консоль.

## Интерфейс

- Одна HTML-страница без сборки (чистый JS), 4 вкладки.
- Зона drag & drop плюс кнопка «выбрать файлы»; список файлов можно сортировать перетаскиванием и удалять из него.
- Кнопка «Сделать» → индикатор работы → автоматическое скачивание результата.

## Тестирование

pytest. Входные файлы генерируются прямо в тестах (Pillow + PyMuPDF):

- images_to_pdf: число страниц = числу картинок; GIF с прозрачностью и JPG обрабатываются; мусор вместо картинки → `PdfToolsError`.
- merge: число страниц = сумме; порядок сохраняется.
- compress: PDF с большой картинкой становится меньше; результат открывается; если сжать нечего, возвращается оригинал.
- pdf_to_epub: результат — валидный ZIP с `mimetype` = `application/epub+zip`; текст и заголовок попадают внутрь; колонтитул убирается; скан → `PdfToolsError`.
- app: эндпоинты отвечают 200 на корректные данные и 400 на некорректные (FastAPI TestClient).

## Зависимости

PyMuPDF, Pillow, ebooklib, FastAPI, uvicorn, python-multipart; для тестов — pytest, httpx.

## Вне рамок

OCR, защита PDF паролем, HEIC, расширение для браузера, упаковка в .exe.
