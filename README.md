# PDF Tools

Локальная программа: картинки → PDF, объединение PDF, сжатие PDF, PDF → EPUB.
Файлы никуда не отправляются — всё работает на этом компьютере.

## Что умеет

Программа открывается в браузере: на странице четыре вкладки, по одной на каждую функцию.

### Картинки → PDF

Склеивает картинки (JPG, GIF, PNG, WEBP) в **один PDF**: одна картинка — одна страница,
размер страницы равен размеру картинки.

- JPG вставляется как есть, без пересжатия — качество не теряется.
- Фото с телефона поворачиваются правильно (учитывается поворот из EXIF).
- У GIF берётся первый кадр, прозрачный фон заменяется белым.
- Результат: `картинки.pdf` (или `готово/<имя папки>.pdf` в режиме папки).

### Объединение PDF

Склеивает несколько PDF в один в заданном порядке. Закладки (оглавление) исходных файлов
сохраняются.
Результат: `объединённый.pdf` (или `готово/<имя папки>.pdf`).

### Сжатие PDF

Уменьшает картинки внутри PDF; текст остаётся текстом (его можно выделять и искать).

| Уровень | Разрешение картинок | Качество JPEG |
|---|---|---|
| лёгкое  | до 200 DPI | 85 |
| среднее | до 150 DPI | 70 |
| сильное | до 100 DPI | 50 |

Показывает размер «было → стало». Если файл не уменьшился, возвращается оригинал.
Результат: файл с тем же именем.

### PDF → EPUB

Делает книгу для читалки на телефоне: текст переносится под ширину экрана, шрифт можно
менять в читалке.

- Строки склеиваются в абзацы, переносы слов убираются.
- Крупный текст становится заголовками глав, по ним строится оглавление.
- Колонтитулы и номера страниц убираются.
- Картинки переносятся в книгу.
- Название и автор берутся из PDF или задаются вручную; если в PDF их нет — название
  по имени файла.

Результат: файл с тем же именем и расширением `.epub`.

## Как пользоваться

1. Запусти программу (см. ниже) — в браузере откроется страница.
2. Выбери вкладку с нужной функцией.
3. Дальше один из двух способов:
   - **Файлы:** перетащи их в рамку или нажми на неё и выбери. Список сортируется по номерам
     в именах, порядок можно поменять перетаскиванием строк, лишний файл — убрать крестиком.
     Нажми «Сделать из выбранных файлов» — результат скачается.
   - **Папка:** вставь путь к папке или нажми «Выбрать папку…», затем «Обработать папку».
     Результаты появятся в подпапке `готово` внутри неё (см. раздел «Папки»).
4. Пока идёт работа, полоса прогресса показывает загрузку файлов в процентах, а затем
   обработку: какая картинка, страница или файл сейчас в работе («Файл 12 из 40: глава 12.pdf»).
   У сжатия одного файла полоса бегущая — библиотека не сообщает, сколько сделано.
5. Кнопка «Сбросить» внизу вкладки очищает её: список файлов, поля, уровень сжатия
   и сообщение. Другие вкладки не меняются.

## Установка (один раз)

Нужен Python 3.10 или новее (разработано на 3.14).

    python -m venv .venv
    .venv\Scripts\python -m pip install -r requirements.txt

## Запуск

    .venv\Scripts\python app.py

Откроется страница http://127.0.0.1:8765. Закрыть программу — Ctrl+C в окне консоли.

## Папки

Укажи папку — обработаются все подходящие файлы в ней (без подпапок) по порядку номеров
в именах (1, 2, …, 10). Результат появится в подпапке `готово`.
Если хотя бы один файл битый, обработка отменяется целиком и ничего не сохраняется —
программа покажет список проблемных файлов.

## Ограничения

- Кнопка «Выбрать папку» требует tkinter (входит в установщик с python.org).
- Сканы без текстового слоя в EPUB не конвертируются (распознавание текста не поддерживается).
- Режим папки обрабатывает всё в памяти: для очень больших папок нужно много оперативной памяти.
