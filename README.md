# PDF Tools

Локальная программа: картинки → PDF, объединение PDF, сжатие PDF, PDF → EPUB.
Файлы никуда не отправляются — всё работает на этом компьютере.

## Установка (один раз)

    python -m venv .venv
    .venv\Scripts\python -m pip install -r requirements.txt

## Запуск

    .venv\Scripts\python app.py

Откроется страница http://127.0.0.1:8765. Закрыть программу — Ctrl+C в окне консоли.

## Папки

Укажи папку — обработаются все подходящие файлы в ней (без подпапок) по порядку номеров
в именах (1, 2, …, 10). Результат появится в подпапке `готово`.
Если хотя бы один файл битый, обработка отменяется целиком и ничего не сохраняется —
программа покажет список проблемных файлов.
